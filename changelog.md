# Kiosk Studio changelog

## 1.1.0 · 2026-11-23

- Added **Autostart** for approved applications, with per-app launch arguments and browser URLs.
- Added **Accounts** for creating users and groups and updating group membership. New accounts are automatically selected for kiosk setup.
- Added **Deployment** to install Cage, deploy the current setup or a saved session, and restore normal boot from the GUI.
- Added a refresh button for the kiosk account list.
- Added settings backup and restore, including startup options and support for importing older session exports.
- Added an in-app user guide and application menu launcher installation.

## 1.0.0 · 2026-11-23

- Added installed application, desktop environment and kiosk runtime detection.
- Added session creation for a standard account and a selected list of apps.
- Added optional boot deployment and rollback using Cage.
- Added custom branding, desktop shortcut installation, and **Help → About**.
